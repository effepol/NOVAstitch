# NOVAstitch 0.1 beta

**Gratuito · Free** — anteprima, informazioni e conversione dei file da ricamo / embroidery file viewer and converter.
Windows 10/11 · macOS 14 o successivo / or later

---

## 🇮🇹 Italiano

NOVAstitch è un gestore di file da ricamo: invece di vedere solo `nomefile.ext`, vedi il ricamo.

**Cosa fa**
- Anteprima a colori di ogni ricamo, in una finestra tipo Esplora Risorse / Finder
- Numero di punti, colori, tagli filo (rasafilo) e dimensioni
- Scheda PDF del ricamo (nome, dati, disegno a grandezza reale o scalato)
- Conversione tra **DST, PES, EXP, JEF** (singolo file o intera cartella; i file originali non vengono toccati)
- Legge anche HUS, SEW, PCS. Il formato ART non è supportato
- Ricerca, ordinamento, interfaccia in italiano e inglese
- Nessuna connessione internet, nessun dato raccolto, nessuna pubblicità

**Scarica** (sezione *Assets* qui sotto)
- Windows: `NOVAstitch-Setup-0.1.exe`
- Mac: `NOVAstitch-0.1.dmg`

**Prima apertura: avvisi normali** — il programma è gratuito e non è firmato con certificati a pagamento, quindi:
- *Windows*: compare "Windows ha protetto il PC". Premi **Ulteriori informazioni → Esegui comunque**.
- *Mac*: trascina NOVAstitch in Applicazioni, prova ad aprirlo, poi **Impostazioni di Sistema → Privacy e sicurezza → Apri comunque** (una volta sola).

Il manuale (italiano e inglese) è nel programma, menu **Manuale**.

## 🇬🇧 English

NOVAstitch is an embroidery file manager: instead of just `filename.ext`, you see the design.

**Features**
- Colour preview of every design in an Explorer/Finder-like window
- Stitch count, colours, trims and dimensions
- PDF sheet per design (name, data, drawing at real size or scaled)
- Conversion between **DST, PES, EXP, JEF** (single file or whole folder; originals are never modified)
- Also reads HUS, SEW, PCS. ART is not supported
- Search, sorting, Italian and English interface
- No internet connection, no data collected, no ads

**Download** (see *Assets* below)
- Windows: `NOVAstitch-Setup-0.1.exe`
- Mac: `NOVAstitch-0.1.dmg`

**First launch: expected warnings** — the app is free and not signed with a paid certificate:
- *Windows*: "Windows protected your PC" → **More info → Run anyway**.
- *Mac*: drag NOVAstitch to Applications, try to open it, then **System Settings → Privacy & Security → Open Anyway** (only once).

The manual (Italian and English) is in the app, **Manual** menu.
